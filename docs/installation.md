# Haukkarin asentaminen

Asennus vaatii tuotannossa HTTPS-osoitteen `https://haukkari.fi/`. Sovellusta
voi käyttää selaimessa ilman asennusta, eikä Web Push -lupaa tarvitse antaa.

## iPhone ja iPad

1. Avaa `https://haukkari.fi/` Safarissa.
2. Paina Jaa-painiketta.
3. Valitse **Lisää Koti-valikkoon** ja vahvista **Lisää**.
4. Avaa Haukkari Koti-valikon kuvakkeesta.

iPhonen Web Push toimii vain kotiin asennetussa verkkosovelluksessa. Haukkari
pyytää ilmoituslupaa vasta käyttäjän omasta painikkeesta Muistutukset-näkymässä.

## Android

1. Avaa `https://haukkari.fi/` Chromessa.
2. Valitse selaimen valikosta **Asenna sovellus** tai **Lisää aloitusnäyttöön**.
3. Vahvista asennus ja avaa Haukkari sovelluskuvakkeesta.

## Työpöytä

Chromessa tai Edgessä avaa `https://haukkari.fi/`, paina osoiterivin
asennuskuvaketta ja vahvista asennus. Safarissa Haukkaria voi käyttää
selainvälilehdessä; työpöytäasennuksen tarkka tuki riippuu käyttöjärjestelmästä ja
selaimen versiosta.

## Päivitys ja poistaminen

Haukkari ilmoittaa, kun uusi versio on valmis. Hyväksy päivitys vasta, kun
keskeneräinen harjoitus on tallennettu. Sovelluksen poistaminen tehdään laitteen
normaalilla sovelluksen poistolla, mutta se ei poista Haukkari-tiliä tai pilveen
synkronoituja tietoja. Tilin pysyvä poisto tehdään Haukkarin Oma tili -näkymästä.
